Publishing settings

Publishing saves published.js to your GitHub repo; Vercel then updates the site. It needs a GitHub token, which is stored only in this browser. To make one:

  1. Open github.com/settings/personal-access-tokens/new (fine-grained token).
  2. Name it e.g. "Parity Blocks publish", pick an expiration.
  3. Repository access: Only select repositories → parity-blocks.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate, copy the token, paste it below.
